# 🤖 Bodka Official Discord Bot

هذا المجلد يحتوي البوت الرسمي المقترح لسيرفر **Bodka Core** العربي.

## ماذا يفعل؟

- ينشئ هيكل السيرفر تلقائيًا بأمر `/تهيئة`.
- ينشئ الرتب والفئات والقنوات والصلاحيات.
- ينشر لوحة القوانين والتحقق الذاتي.
- ينشر قائمة اختيار الرتب والاهتمامات.
- ينشئ نظام تذاكر دعم خاصة.
- يدعم اقتراحات وبلاغات أعطال عبر نماذج Discord.
- يعرض حالة مشروع Bodka من GitHub.
- يراقب آخر Commit وRelease وPull Request وIssue وحالة GitHub Actions.
- يمكنه تحويل بلاغات الأعطال إلى GitHub Issues عند تفعيل ذلك.

## المتطلبات

- Node.js 20 أو أحدث.
- تطبيق Discord Bot من بوابة المطورين.
- صلاحيات للبوت: Manage Roles, Manage Channels, Manage Messages, Manage Webhooks, Moderate Members, View Audit Log.
- يجب أن تكون رتبة البوت أعلى من الرتب التي سيقوم بإدارتها.
- فعّل Server Members Intent إذا أردت رسالة الترحيب التلقائية عند دخول الأعضاء.

## تشغيل سريع

1. انسخ `.env.example` إلى `.env`.
2. ضع `DISCORD_TOKEN` و`DISCORD_CLIENT_ID`.
3. اختياريًا ضع `DISCORD_GUILD_ID` لتسجيل الأوامر فورًا داخل سيرفر واحد.
4. نفّذ `npm install`.
5. نفّذ `npm start`.
6. أضف البوت إلى السيرفر بصلاحيات الإدارة المطلوبة.
7. من حساب مالك السيرفر شغّل `/تهيئة`.

## ربط GitHub

القيمة الافتراضية للمستودع:

`aboodksa4011/Bodka-Core`

للمستودع العام لا تحتاج Token للقراءة الأساسية، لكن يفضّل `GITHUB_TOKEN` لتقليل حدود GitHub API. إذا أردت أن يحوّل `/بلاغ` البلاغ إلى Issue فعلي، ضع Token بصلاحية Issues للمستودع ثم اجعل:

`CREATE_GITHUB_ISSUES=true`

> لا ترفع `.env` أو Discord Token أو GitHub Token إلى GitHub.

## القنوات والرتب

أمر `/تهيئة` ينشئ أقسام البداية، بودكا كور، الدعم، التطوير وGitHub، المجتمع، الصوتيات، التذاكر والإدارة. كذلك ينشئ رتب المؤسس، الإدارة، المطورين، الدعم، مختبر بيتا، المساهمين، الإشعارات والعضو الموثق.

## الأمان

- لا يوجد أي Token أو Webhook خاص داخل المستودع.
- بلاغات الأعطال تنبّه المستخدم صراحةً لحذف البيانات الحساسة من السجلات.
- التذاكر خاصة بصاحبها وفريق الإدارة/الدعم.
- إنشاء GitHub Issues من Discord معطل افتراضيًا حتى يتم تفعيله يدويًا.

## ملاحظة

البوت لا يحذف القنوات القديمة تلقائيًا. أمر `/تهيئة` مصمم ليكون آمنًا قدر الإمكان: يبحث عن العناصر الموجودة ويحدّث أو يكمل الناقص بدل صنع نسخ مكررة.
