# Bodka Core Source Review

هذا المجلد موجود حتى يكون تقييم Bodka Core مبنياً على كود حقيقي قابل للمراجعة، وليس على ملف Installer ووصف المشروع فقط.

## ما الموجود هنا؟

عينات من إضافات Bodka Core الخاصة، مأخوذة من النسخة العامة المنقحة أمنياً للإصدار 0.8.0. تم اختيارها لأنها تمثل أنواعاً مختلفة من العمل داخل المشروع مثل الخصوصية، تنظيف الروابط، حماية المنشنات، وتحليل إشارات الحساب محلياً.

## لماذا ليست هذه نسخة Vencord كاملة؟

لأن الهدف هنا هو إظهار كود Bodka القابل للتقييم مباشرة، مع عدم إعادة نسب بنية upstream بالكامل إلى المشروع. Bodka Core يعتمد جزئياً على Vencord، وتبقى حقوق ومساهمات Vencord لأصحابها.

## الأمان

لا يجب أن تحتوي الملفات المنشورة هنا على API keys أو Tokens أو Passwords أو Cookies أو Webhooks خاصة. النسخة العامة تُفحص قبل النشر، لكن أي مفتاح تم كشفه سابقاً يجب تدويره من مزوده ولا يكفي حذفه من Git.

## الترخيص

رؤوس SPDX وإشعارات Vencord الموجودة داخل الملفات محفوظة كما هي. راجع `ATTRIBUTION.md` و`SECURITY.md` في جذر المستودع.
