# Bodka Core | بودكا كور

> **Customize. Extend. Make it yours.**

**Bodka Core** هو مشروع Windows لتخصيص وتوسيع تجربة Discord من مكان واحد، مع إدارة الإضافات، الثيمات، العبارات، الأدوات والتشخيص. المشروع يركز على تجربة عربية واضحة، الخصوصية، سهولة الاستخدام، والشفافية في الفصل بين كود Bodka الخاص والمكونات المفتوحة المصدر التي يعتمد عليها.

## المطور

تم تطوير **Bodka Core** بواسطة المطور السعودي **عبدالله مسلم الجهني**.

الهدف من المشروع هو بناء تجربة تخصيص قوية ومنظمة لمستخدمي Discord على Windows، مع أدوات عربية وإضافات خاصة بالمشروع، والاستفادة بشكل شفاف من بنية ومشاريع مفتوحة المصدر مثل Vencord عند الحاجة.

## ماذا يقدم Bodka Core؟

- إدارة الإضافات من واجهة موحدة.
- تخصيص شكل وتجربة Discord عبر الثيمات والإعدادات.
- أدوات للتعامل مع عبارات Discord وتخصيصها.
- إضافات Bodka خاصة للخصوصية والأدوات والإنتاجية والتخصيص.
- أدوات تشخيص ومساعدة للمطورين.
- واجهة عربية مع تركيز على سهولة الاستخدام.
- نظام قابل للتوسع مع استمرار تطوير الإضافات والأدوات.

## كود قابل للمراجعة

حتى لا يكون تقييم المشروع مبنياً على `Installer.exe` والوصف فقط، توجد عينات فعلية من كود Bodka المنقح أمنياً داخل:

`source-review/`

ومن الأمثلة المنشورة حالياً:

- `BodkaPrivacyShield` — إخفاء رموز الدخول ومفاتيح الخدمات وروابط Webhook قبل الإرسال بالخطأ.
- `BodkaLinkCleaner` — تنظيف وسوم التتبع المعروفة من الروابط محلياً.
- `BodkaMentionGuard` — تقليل أخطاء المنشنات العامة والتنبيه عند كثرة المنشنات.
- `BodkaAccountSignals` — تحليل عمر حساب Discord محلياً من Snowflake وإظهار إشارة داخل واجهة المشروع.

راجع `source-review/README.md` لمعرفة الغرض من مجلد المراجعة.

## التثبيت

1. حمّل `BodkaCoreInstaller.exe` من هذا المستودع.
2. شغّل المثبت على Windows.
3. اتبع تعليمات التثبيت الظاهرة في البرنامج.
4. راجع ملف **دليل الاستخدام بودكا كور** الموجود في المستودع للتفاصيل.

> يفضّل تنزيل الملفات من هذا المستودع الرسمي فقط. لا تدخل رموز حساب Discord أو بيانات تسجيل الدخول في ملفات أو أدوات غير موثوقة.

## البنية والترخيص

Bodka Core **ليس مشروعاً مكتوباً بالكامل من الصفر**. النسخة الحالية تستخدم أو تعدل أجزاء من Vencord ومشاريع مفتوحة المصدر أخرى. حقوق تلك الأجزاء تبقى لأصحابها الأصليين وتخضع لتراخيصها الأصلية.

للتفاصيل:

- `ARCHITECTURE.md` — شرح بنية المشروع والطبقات الرئيسية.
- `ATTRIBUTION.md` — توضيح الفرق بين كود Bodka ومكونات upstream.
- `QUALITY.md` — ما هو موثق وما هو متحقق منه وما يزال مخططاً له.
- `SECURITY.md` — سياسة التعامل مع المصدر العام والأسرار.
- `CHANGELOG.md` — سجل التغييرات.
- `ROADMAP.md` — خطة التطوير.
- `CONTRIBUTING.md` — إرشادات المساهمة.

## الأمان

لا تضع أي API key أو Token أو Password أو Cookie أو Webhook أو ملف `.env` شخصي داخل النسخة العامة من المشروع.
