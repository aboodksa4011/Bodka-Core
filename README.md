# Bodka Core | بودكا كور

> **Customize. Extend. Make it yours.**

**Bodka Core** هو مشروع Windows لتخصيص وتوسيع تجربة Discord من مكان واحد، مع إدارة الإضافات، الثيمات، العبارات، الأدوات والتشخيص.

## المطور

تم تطوير **Bodka Core** بواسطة المطور السعودي **عبدالله مسلم الجهني**، كمشروع يركز على بناء تجربة تخصيص قوية ومنظمة وسهلة الاستخدام لمستخدمي Discord على Windows.

## ماذا يقدم Bodka Core؟

- إدارة الإضافات من واجهة موحدة.
- تخصيص شكل وتجربة Discord عبر الثيمات والإعدادات.
- أدوات للتعامل مع عبارات Discord وتخصيصها.
- أدوات تشخيص ومساعدة للمطورين.
- واجهة عربية مع تركيز على سهولة الاستخدام.
- نظام قابل للتوسع مع استمرار تطوير الإضافات والأدوات.

## التثبيت

1. حمّل `BodkaCoreInstaller.exe` من هذا المستودع.
2. شغّل المثبت على Windows.
3. اتبع تعليمات التثبيت الظاهرة في البرنامج.
4. راجع ملف **دليل الاستخدام بودكا كور** الموجود في المستودع للتفاصيل.

> يفضّل تنزيل الملفات من هذا المستودع الرسمي فقط. لا تدخل رموز حساب Discord أو بيانات تسجيل الدخول في ملفات أو أدوات غير موثوقة.

## ملاحظة

Bodka Core مشروع غير رسمي لتخصيص Discord. اسم Discord وعلاماته التجارية تعود لأصحابها، ولا يعني ذكرها وجود شراكة أو اعتماد رسمي.

حيثما يستخدم Bodka Core مكونات أو تعديلات مبنية على مشاريع مفتوحة المصدر مثل Vencord، يجب الحفاظ على تراخيص وإسناد تلك المشاريع كما هو مطلوب.
